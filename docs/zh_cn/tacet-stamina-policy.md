# 无音区耗体力策略

领取奖励确认弹窗上有两个按钮：

| 状态 | 含义 | 行为 |
| --- | --- | --- |
| 120 **白字** | 双倍可领 | **优先点双倍**（`TacetClaimStaminaDouble`） |
| 120 **红字**、60 **白字** | 仅单倍可领 | 点单倍（`TacetClaimStamina`） |
| 60 与 120 **皆红字** | 体力不足，无法领取 | **结束无音区任务并标记已完成**；置位「体力耗尽」，**后续所有耗体力任务一律跳过** |

实现备注：

- Pipeline 节点顺序：先匹配双倍模板，再单倍，再 `TacetStaminaExhausted`（点弹窗 X 关闭）。
- 跨任务跳过耗体：由 Interface / Go 在命中耗尽后写全局标志（待接）。
