# 路线图

## 原则

1. **Pipeline 管流程，Go 管难点**：日常跳转与点击用 JSON；战斗循环、角色识别等进 `agent/go-service`。
2. **先有截图再写节点**：每个识别节点需要安卓 720p 截图、`roi`、界面跳转说明。
3. **功能对标 ok-ww，运行时对标 MaaEnd**：行为对齐 ok-ww，工程与控制器对齐 MaaFramework / MaaEnd。
4. **第一期只做模拟器 ADB**：不优先 Win32。
